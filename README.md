# GP Evidence Library

A static, responsive A-Level General Paper revision website.

## Features
- Black top bar with a collapsible secondary menu.
- Essay-question themes nested under the menu; homepage remains search-first.
- Multi-category filtering, keyword search, and sorting.
- Evidence cards with essay-ready phrasing, key statistics, counterarguments, evaluation notes, question matches, category tags, and original article links.
- Save/bookmark examples in the browser, copy essay paragraphs, and open source links.
- Responsive layout, Apple system-font stack, subtle nonlinear motion, and reduced-motion support.
- No build tools or dependencies required.

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Choose deployment from the `main` branch and `/ (root)`.
5. Save and wait for the published URL.

## Research and accuracy notes
The starter bank of 17 examples was researched using linked articles from CNA and The Straits Times, and The Guardian. Every case includes links to original articles. Statistics can change as new reports are published; check the linked article for the full methodology and context before quoting.

Some figures are estimates, forecasts or survey results rather than directly observed outcomes. The case cards label these distinctions where relevant. Do not equate AI job exposure with actual job losses, online-content exposure with belief, or scam case counts with total financial losses.

## Important limitation about provided Drive links
The Google Docs and Google Drive folder links shared in the conversation were not readable through the available connected tools, so their contents (including AQ papers and school prelim questions) are not imported yet. The question index is a curated starter set based on the public essay-question archive linked below, not a complete archive of every paper.
