# GP Evidence Library — iOS/iPadOS-inspired redesign

A static website intended for GitHub Pages. Open `index.html` locally or upload the files to a GitHub repository and enable GitHub Pages.

## Included
- Responsive layout for desktop, tablet and phone
- Apple system-font stack (SF fonts where available)
- Floating Liquid Glass-inspired panels and slower, smoother transitions
- Search and category filters, question menu, bookmarks, source links and essay-ready application
- Settings panel for light/dark appearance, accent colour, reduced motion and showing/hiding Singapore Trait links
- Suggested trait links attached to Singapore-related examples based on the example text

## Important notes
- This is a static, offline-friendly starter. Bookmarks and preferences may reset after reload.
- Trait links are heuristic suggestions based on the example text, not an authoritative classification. Review each connection before using it in an essay.
- Verify statistics, dates and source context against original publications before quoting.
- Some content is adapted from user-provided class resources. This package is for personal study; do not redistribute original school handouts.
- The visual style is inspired by iOS/iPadOS conventions, not an official Apple interface.
