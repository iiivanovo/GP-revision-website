# GP Evidence Library — Final Build

Open `index.html` in a modern browser. The site is self-contained and can be hosted on GitHub Pages.

## Included
- iOS-inspired Liquid Glass layout using the Apple system font stack.
- Consistent unified corner-radius tokens and progressive continuous-corner support where browsers support `corner-shape`.
- Home dashboard, all-category grid, category examples, example detail tabs, argument view, essay paragraph starter, Singapore Traits, key concepts, current issues, and settings.
- Existing evidence, source notes, argument notes, topic primers, and 24 Singapore Traits are retained from the supplied GP Fieldnotes HTML.

## Evidence quality
Source summaries and argument/evaluation notes are preserved from the source file. A generated paragraph starter is a starting point, not a complete model answer. Some category counts are based on keyword matching across the source bank; empty categories are labelled rather than filled with invented examples. Saved examples are session-only in this build.
